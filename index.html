Chapter 02 - Setup

Installation & Project Setup

Follow these precise steps to set up your local development environment.

1. Create Virtual Environment

python -m venv .venv

2. Activate Environment

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

3. Install Django & Initialize Project

pip install django
django-admin startproject config
cd config
python manage.py runserver
💡

Access your local development server at http://127.0.0.1:8000

🏗️
Chapter 03 - Architecture

MVT Architecture

Django follows the Model-View-Template architectural pattern.

Layer Role & Description
Model Acts as the data source and handles database schema mapping.
View Processes requests, executes business logic, and returns responses.
Template Handles the HTML user interface presentation logic.

Chapter 04 - Routing

URL Routing

URLconfs route browser requests to the appropriate view function.

from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("core.urls")),
]

Chapter 05 - Logic

Views & Templates

Views receive web requests and return web responses using template rendering.

from django.shortcuts import render

def home_view(request):
    context = {"message": "Welcome to Django Masterclass!"}
    return render(request, "home.html", context)

Chapter 06 - Modularization

Apps & Forms

Django apps separate features into modular, reusable components.

python manage.py startapp products

Define Django Form

from django import forms

class ProductForm(forms.Form):
    title = forms.CharField(max_length=100)
    price = forms.DecimalField(max_digits=8, decimal_places=2)

Chapter 07 - Database

Models & Django ORM

Define database tables using elegant Python classes.

from django.db import models

class Item(models.Model):
    name = models.CharField(max_length=120)
    in_stock = models.BooleanField(default=True)

    def __str__(self):
        return self.name

Chapter 09 - Protection

Authentication System

Secure views by checking user authentication status directly inside request instances.

from django.shortcuts import redirect

def dashboard_view(request):
    if not request.user.is_authenticated:
        return redirect("login")
    return render(request, "dashboard.html")

Chapter 12 - Hardening

Security Best Practices

  • Keep DEBUG = False in production servers.
  • Protect sensitive keys using environment variables.
  • Maintain precise control over ALLOWED_HOSTS.
  • Always leverage built-in CSRF and SQL injection protections.

Chapter 14 - Cheat Sheet

Essential Django Commands

Command Functionality
python manage.py runserver Launches the local development server
python manage.py startapp [name] Scaffolds a new module application
python manage.py makemigrations Creates structural migration files
python manage.py migrate Applies database schema updates
python manage.py shell Opens interactive Python shell with app context
python manage.py collectstatic Gathers static assets for deployment

Chapter 15 - Mastery

Professional Best Practices

  • Always isolate project environments utilizing virtual environments.
  • Maintain updated requirement logs inside dependency manifests.
  • Structure complex apps logically into clean modular sub-packages.
  • Test business logic rigorously using built-in testing tools.

Mastery Rule: Never hardcode configurations. Rely entirely on environment variables for production security.
